Installer un nœud

Un nœud et son portefeuille de bureau, installés dans votre dossier personnel, sans droits d'administrateur. Le nœud lit la chaîne d'essai sur le miroir public et la rejoue depuis le bloc 0, avec la clé du producteur épinglée dans l'installateur. Deux clés ed25519 sont créées sur votre machine ; le logiciel ne les transmet jamais.

Choisissez votre système. Chaque commande se copie d'un clic ; lisez l'installateur avant de le lancer, c'est un script en clair suivi d'une archive du code du dépôt.

Linux Windows macOS Android (Termux)

Linux

Testé sous Linux le 2 novembre 2026 : installation, lecture du miroir, chaîne rejouée

Prérequis

  • Python 3.10 ou plus récent, ssh-keygen (paquet openssh-client) et curl. Sous Debian ou Ubuntu, s'ils manquent : sudo apt install python3 openssh-client curl.
  • Rien d'autre ne demande de droits d'administrateur : le nœud tourne avec votre compte.
  1. Téléchargez l'installateur et vérifiez son empreinte. 
    curl -LO https://turbo31150.github.io/vision/installer-noeud-vision.sh
curl -LO https://turbo31150.github.io/vision/installer-noeud-vision.sh.sha256
sha256sum -c installer-noeud-vision.sh.sha256
  2. Lisez-le, puis lancez-le. 
    less installer-noeud-vision.sh
bash installer-noeud-vision.sh --nom mon-noeud
  3. Ouvrez le portefeuille par l'icône « VISION Portefeuille » du menu des applications, ou par la commande affichée à la fin de l'installation.

Ce qui est posé : le code et les clés dans ~/.local/share/vision-noeud, un service systemd --user (vision-noeud.service) qui démarre avec votre session, l'icône du menu. Sans systemd, ou avec --sans-systemd, le nœud tourne en arrière-plan et écrit son journal dans noeud.log.

Désinstaller

bash installer-noeud-vision.sh --desinstaller

Le nœud est arrêté et son code retiré ; vos clés et votre copie de la chaîne restent dans ~/.local/share/vision-noeud. Le dossier portefeuille/ contient votre clé : gardez-le.

Windows 10 et 11

Non testé sur ce système : écrit pour Windows 10 et 11, pas encore essayé sur une machine Windows

Prérequis

  • Python 3.10 ou plus récent, depuis python.org (gardez le lanceur py) ou le Microsoft Store.
  • Client OpenSSH de Windows, pour ssh-keygen : présent d'origine sur les versions récentes ; sinon, Paramètres, Système, Fonctionnalités facultatives, « Client OpenSSH ».
  • Windows 10 version 1803 ou plus récente, pour curl.exe et tar.exe. Aucun droit d'administrateur n'est demandé.
  1. Dans PowerShell, téléchargez l'installateur et vérifiez son empreinte : la dernière commande doit afficher True. 
    cd $env:USERPROFILE\Downloads
curl.exe -LO https://turbo31150.github.io/vision/installer-noeud-vision.ps1
curl.exe -LO https://turbo31150.github.io/vision/installer-noeud-vision.ps1.sha256
(Get-FileHash .\installer-noeud-vision.ps1 -Algorithm SHA256).Hash -eq (Get-Content .\installer-noeud-vision.ps1.sha256).Split(' ')[0]
  2. Lisez-le (un script PowerShell en clair, suivi de l'archive du code), puis lancez-le. 
    notepad .\installer-noeud-vision.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\installer-noeud-vision.ps1 -Nom mon-pc
  3. Ouvrez le portefeuille par le raccourci « VISION Portefeuille » du menu Démarrer ou du Bureau : il ouvre http://127.0.0.1:8861/ avec le passe local, qui seul permet de signer.

Ce qui est posé : le code et les clés dans %LOCALAPPDATA%\VISION\noeud, le nœud lancé en arrière-plan sans fenêtre (pythonw, journal noeud.log), une tâche planifiée « VISION noeud » à l'ouverture de votre session (si Windows la refuse, un raccourci dans le dossier Démarrage la remplace) et le raccourci « VISION Portefeuille ». Options : -Pair, -Miroir, -Api, -P2p, -Prefixe, -SansTache, -SansRaccourci.

Désinstaller

powershell -NoProfile -ExecutionPolicy Bypass -File .\installer-noeud-vision.ps1 -Desinstaller

Le nœud est arrêté, la tâche planifiée et les raccourcis retirés ; vos clés restent dans %LOCALAPPDATA%\VISION\noeud. Le dossier portefeuille\ contient votre clé : gardez-le.

macOS

Non testé sur ce système : écrit pour macOS, pas encore essayé sur un Mac

Prérequis

  • Python 3.10 ou plus récent : le python3 fourni avec les outils de développement d'Apple est souvent plus ancien. Installez-le depuis python.org, puis lancez une fois « Install Certificates.command » (dossier Applications, Python 3.x), ou par Homebrew : brew install python.
  • ssh-keygen et curl sont fournis avec macOS. Aucun droit d'administrateur n'est demandé.
  1. Dans le Terminal, téléchargez l'installateur et vérifiez son empreinte. 
    curl -LO https://turbo31150.github.io/vision/installer-noeud-vision.sh
curl -LO https://turbo31150.github.io/vision/installer-noeud-vision.sh.sha256
shasum -a 256 -c installer-noeud-vision.sh.sha256
  2. Lisez-le, puis lancez-le. 
    less installer-noeud-vision.sh
bash installer-noeud-vision.sh --nom mon-mac
  3. Ouvrez le portefeuille par l'application « VISION Portefeuille » de votre dossier Applications personnel (~/Applications).

Ce qui est posé : le code et les clés dans ~/.local/share/vision-noeud, un agent de session launchd (~/Library/LaunchAgents/io.github.turbo31150.vision-noeud.plist) qui démarre le nœud à l'ouverture de session et le relance après un échec, et l'application « VISION Portefeuille ». Le journal est dans noeud.log.

Désinstaller

bash installer-noeud-vision.sh --desinstaller

Le nœud est arrêté, l'agent et l'application retirés ; vos clés restent dans ~/.local/share/vision-noeud. Le dossier portefeuille/ contient votre clé : gardez-le.

Android, avec Termux

Non testé sur un téléphone : écrit pour Termux, pas encore essayé sur un appareil Android

Prérequis

  • Termux, installé depuis F-Droid ou les publications GitHub du projet Termux, pas depuis le Play Store.
  • Termux:Widget, si vous voulez un raccourci sur l'écran d'accueil : il doit venir de la même source que Termux.
  • Dans Termux : pkg install python openssh curl. Aucun accès administrateur (root) n'est demandé.
  1. Dans Termux, installez les paquets, téléchargez l'installateur et vérifiez son empreinte. 
    pkg install python openssh curl
curl -LO https://turbo31150.github.io/vision/installer-noeud-vision.sh
curl -LO https://turbo31150.github.io/vision/installer-noeud-vision.sh.sha256
sha256sum -c installer-noeud-vision.sh.sha256
  2. Lisez-le, puis lancez-le. Termux est reconnu : le nœud tourne en arrière-plan, sans service système. 
    less installer-noeud-vision.sh
bash installer-noeud-vision.sh --nom mon-telephone
termux-wake-lock
  3. Ajoutez le widget Termux:Widget sur l'écran d'accueil et choisissez « VISION Portefeuille » : il relance le nœud si Android l'a arrêté, puis ouvre le portefeuille dans le navigateur.

Ce qui est posé : le code et les clés dans ~/.local/share/vision-noeud (dans l'espace privé de Termux), le nœud en arrière-plan (journal noeud.log) et le raccourci ~/.shortcuts/VISION Portefeuille. Android peut arrêter Termux en arrière-plan : termux-wake-lock le garde éveillé, au prix de la batterie. Le portefeuille n'écoute que sur le téléphone lui-même (127.0.0.1).

Désinstaller

bash installer-noeud-vision.sh --desinstaller

Le nœud est arrêté, le raccourci et le code retirés ; vos clés restent dans ~/.local/share/vision-noeud. Le dossier portefeuille/ contient votre clé : gardez-le.

Après l'installation

  • Le portefeuille n'est servi que sur votre machine, à http://127.0.0.1:8861/. Ouvert par l'icône ou le raccourci, il reçoit le passe local et peut signer ; l'adresse seule donne une lecture sans signature.
  • La chaîne est lue sur le miroir public et rejouée depuis le bloc 0 : liens, racines de Merkle, soldes, signatures. Un miroir ne peut rien imposer au nœud.
  • L'inscription se prépare dans l'onglet Nœud : une transaction signée par la clé du nœud, qui ne contient que des données publiques, s'ouvre en ticket sur le dépôt.

Vérifier l'installateur

  • Les empreintes publiées : installer-noeud-vision.sh.sha256 (Linux, macOS, Android) et installer-noeud-vision.ps1.sha256 (Windows).
  • La reconstruction : les deux installateurs se reconstruisent à l'identique à partir du dépôt, sous Linux, avec installateur/construire-installateur. La clé publique du producteur et l'empreinte du bloc 0 viennent de docs/chaine/info.json.
  • Le même code partout : les deux installateurs contiennent la même archive (nœud, outil de chaîne, portefeuille) et épinglent les mêmes valeurs.
